# ГрузШер КБР

Нативный Android-прототип грузового каршеринга для Нальчика и КБР.

## Как получить тестовый APK v2.3

1. Скачать `GruzSher-KBR-v2.3-alpha-CI-source.zip` из беседы ChatGPT.
2. Открыть [загрузку файлов в этот репозиторий](https://github.com/Xalidmuslim/GruzSher-KBR/upload/main).
3. Добавить ZIP **целиком, не распаковывать и не переименовывать**. Подтвердить Commit changes.
4. Открыть [GitHub Actions](https://github.com/Xalidmuslim/GruzSher-KBR/actions) и дождаться завершения задания «Import v2.3 source and build Android APK».
5. Открыть успешный запуск, в разделе Artifacts загрузить `GruzSher-KBR-v2.3-preview-APK`, распаковать артефакт и установить `app-debug.apk`.

CI проверяет SHA-256 загруженного ZIP перед извлечением, запускает серверные тесты и Android unit tests, затем собирает **debug APK**.

## Важно

- **v2.3 — демонстрационная сборка, не коммерческий каршеринг.** SMS, проверка документов, реальные платежи, сервер и автомобильная телематика не подключены.
- Внутри Android используется offline-demo, который не списывает деньги и не управляет дверями.
- Для публикации и реальной эксплуатации требуется отдельная архитектурная, функциональная и юридическая проверка.
- Репозиторий сейчас публичный. Перед добавлением клиентских данных, ключей или коммерческих материалов смените видимость на Private.

Последняя известная стабильная Android APK — v1.0, она не заменяется этим проектом.
