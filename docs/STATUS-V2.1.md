# ГрузШер КБР — v2.1 Alpha · разработка продолжается

## Что изменено относительно v2.0 Alpha

**Сервер (демо, без управления машиной):**
- Новые статусы: `PENDING` → `CONFIRMED` → `ACTIVE` → `COMPLETED`; отмена доступна до `ACTIVE`.
- Только администратор может зафиксировать ручную выдачу (`POST /v1/admin/bookings/{id}/handover`) и ручной возврат (`POST /v1/admin/bookings/{id}/return`). Эти вызовы никогда не открывают двери и не списывают деньги.
- Проверка корректной последовательности статусов: повторная выдача / возврат возвращает HTTP 409.
- История событий `GET /v1/bookings/{id}/timeline` с UTC-временем. Пользователь видит только собственную заявку; демосессия общая, настоящей идентификации людей пока нет.
- Продемонстрирована отдельная таблица истории `booking_events`; приложение может отобразить последовательность действий.
- Подтверждение/отмена теперь записываются в историю; повтор отмены не дублирует событие.

**Android (исходники):**
- Экран «Поездки»: статус, стоимость, начало/конец, визуальные этапы, список событий.
- Запрет отмены после ручной выдачи, неудачные запросы возвращают ошибку.
- Защита от повторного нажатия «Отправить заявку» и одинаковый `Idempotency-Key` для повтора одного намерения.
- Обособленный debug-пакет `ru.kbr.cargoshare.preview`, чтобы не затереть установленный v1.0.

**Админка:**
- Поэтапные кнопки «Подтвердить заявку», «Отметить выдачу (демо)», «Отметить возврат (демо)».
- Предупреждение перед фиксацией выдачи/возврата.

## Проверки
- Python: 24/24 backend тестов успешно.
- Kotlin pure rules: отдельный `kotlinc` smoke-тест прошёл.
- JavaScript: `node --check backend/app/admin.js` успешно.
- Android Gradle/APK: **не проверено** — в текущей среде нет Android SDK и Gradle. Код Android может потребовать правки после первой настоящей сборки.
- CI workflow теперь запускает `testDebugUnitTest` перед `assembleDebug`, но пока не запускался.

## Ограничения
Это развитие демонстрационного исходного проекта v0.2, а **не восстановленный исходник APK v1.0**. Не переносите его поверх рабочего установленного приложения. Документы, настоящие SMS, платежи, телематика, фотоосмотр, страховка и production-операции не подключены. Сервер локальный на SQLite, с общей demo-учётной записью и единым демо-ключом администратора, поэтому **не допускается публиковать этот backend в открытый интернет**.

## Как получить APK после подключения репозитория
- Создайте **отдельный** GitHub-репозиторий, поместите туда содержимое корня `KBR-CargoShare`.
- Запустите GitHub Actions → `Build Android demo APK`.
- CI запускает юнит-тесты и сборку, загружает `app-debug.apk` как артефакт.
- На реальном телефоне без адреса HTTPS-сервера будет только офлайн-демо каталога и карты. Бронирование работает только при доступе к демо API.
