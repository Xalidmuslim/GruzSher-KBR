# ГрузШер КБР — v2.2 Alpha / Offline Preview

**Статус:** исходники Android/Server. Не production APK и не реальный каршеринг.
**Дата:** 18 октября 2026.

## Что изменилось после v2.1

### Android
- Когда локальный демосервер недоступен, debug-приложение позволяет полностью попробовать **учебное бронирование на телефоне**: открыть карточку → выбрать время → рассчитать цену → создать демонстрационную заявку → увидеть в «Поездках» → отменить.
- Для одного автомобиля пересекающиеся учебные заявки недопустимы. Граничные случаи (другой автомобиль, непересекающиеся интервалы, отмена) обработаны чистыми Kotlin-правилами.
- Состояние офлайн-демо хранится только в оперативной памяти приложения: оно **не является бронированием**, не отправляется оператору и не переживает закрытие процесса. Нет оплаты, SMS, KYC и открывания дверей.
- Время аренды валидируется перед расчётом и подтверждением: начало в будущем, не далее 90 дней, длительность 2 часа–30 дней.
- Ответ по цене со старыми датами более не активирует кнопку бронирования после их изменения. Исправлена смена даты из 29 февраля на обычный год.
- OSMDroid MapView при уходе с экрана освобождает ресурсы и при незначительной перекомпоновке Compose повторно не создаёт маркеры.
- Добавлена метка «ОФЛАЙН-СИМУЛЯЦИЯ» и предупреждения о демонстрационной природе машины и заявок.
- `applicationId=ru.kbr.cargoshare.preview`, отдельный от v1.0 пакет.

### Demo API
- Исправлено устаревание неподтверждённых броней: по истечении 20 минут статус становится `EXPIRED` и событие `EXPIRED` добавляется в журнал **один раз**.
- Расчёт доступности, история пользователя, администратора, отмена, подтверждение и повторный запрос с Idempotency-Key учитывают этот статус. Истёкшая бронь больше не выглядит ожидающей и не блокирует слот.
- Старые подтверждённые/активные бронирования автоматически не истекают.
- Расширены тесты API до 26 кейсов, включая переход и повторение истёкшей брони.

## Как собрать Preview APK

1. Создайте **отдельный** репозиторий GitHub для ГрузШер, не используйте ветки других приложений.
2. Положите содержимое папки `KBR-CargoShare` в корень репозитория.
3. Откройте Actions → `Build Android demo APK` → Run workflow. В workflow Gradle 8.9, Android SDK 35, unit tests, assembleDebug и загрузка APK.
4. Установите скачанный debug APK рядом со старой v1.0 (у версии v2.2 другой applicationId).
5. На физическом телефоне без локального API должен работать офлайн-каталог, расчёт цены и учебное бронирование; реальные карты OSM требуют интернета. Подключение к `10.0.2.2:8000` доступно только в Android Emulator и не является сервером для телефона.

## Что остаётся до уровня конкурентов

1. Восстановить актуальные исходники v1.0, объединить их с v2.x (APK не заменяет Git-исходники).
2. Пройти настоящий Android CI и тестирование на устройстве, исправить возможные ошибки компиляции/плавности.
3. Развернуть HTTPS API с нормальной авторизацией, хранением данных, аудитом событий и блокировками бронирований для конкурирующих транзакций.
4. Подключить подтверждение номера, лицензированную проверку документов, платежи/возвраты и электронные договоры.
5. Отдельно оценить телематику грузовиков, страхование, зоны аренды, регламент по ДТП и технической поддержке.

**Запрещено выдавать офлайн-заявки за реальные; публикация demo backend во внешнюю сеть опасна.**
