# ГрузШер КБР v2.3 Alpha · CI-ready

## Что изменилось с v2.2
- Демонстрационная Android-сборка **по умолчанию автономна**: приложение не выполняет скрытые запросы к `10.0.2.2` (адрес, доступный только эмулятору). Начальная карта и демонстрационная аренда должны открываться даже без работающего backend; тайлы OSM требуют интернета.
- Подключение локального демосервера разрешается явно `gradle assembleDebug -PdemoServerEnabled=true`, только при запуске в эмуляторе Android с backend на машине разработчика.
- GPS-кнопка после выдачи точного разрешения ожидает координату и сама переводит карту к текущему положению; предупреждает через 15 секунд при отсутствии координаты.
- GitHub Actions: backend-тесты, Android JVM-тесты, `assembleDebug`, проверка APK, SHA256 и загрузка артефакта на 30 дней.
- `applicationId=ru.kbr.cargoshare.preview`: v2.3 Preview устанавливается **отдельно от v1.0**, если у v1.0 иной идентификатор.

## Публикация и сборка
1. Создать НОВЫЙ пустой репозиторий GitHub `GruzSher-KBR` (пока в подключённом аккаунте он не найден). Не загружать в репозитории других приложений.
2. Разместить **содержимое** корня этого архива в корне репозитория, включая каталог `.github` (сам ZIP GitHub Actions не распакует). В репозитории должны быть пути `android/app/build.gradle.kts`, `backend/`, `.github/workflows/android-debug.yml`.
3. Открыть **Actions → GruzSher Preview · Android APK → Run workflow** (либо выполнить push в `main`).
4. После зелёной сборки скачать в разделе **Artifacts** архив `GruzSher-KBR-v2.3-preview-APK`. Внутри `app-debug.apk` и SHA256SUMS.txt.
5. На Android-устройстве разрешить установку APK только если доверяете источнику. Debug APK тестовый, НЕ распространять клиентам и не загружать в Google Play.

## Важно
- В этой среде Android SDK, Gradle и доступ к удалённым репозиториям зависимостей отсутствуют; APK v2.3 не был собран и Android instrumented tests не запускались.
- Сервер тестировался локально. Платёжные операции, реальные документы, SMS, телематика и дистанционное открытие грузовиков **НЕ** реализованы.
- APK v1.0 не модифицирован, его исходник по-прежнему не найден; новая preview-база восходит к исходнику v0.2 и не гарантирует сохранение всех функций v1.0.
