## Контракт карты

- GET `/v1/vehicles` содержит опциональные `latitude`, `longitude`. Оба null — нет точки.
- GET `/v1/map/vehicles` отдаёт только опубликованные автомобили с обоими координатами; `positionSource = ADMIN_STATIC`.
- PATCH `/v1/admin/vehicles/{id}` принимает `latitude` и `longitude` ТОЛЬКО совместно. Оба null убирают точку. Другие поля остаются обратно совместимы.
- Показанная точка не означает фактическое положение автомобиля: без телематики это операторская статическая точка выдачи.

## Приоритет дальнейших шагов

1. Найти Android-исходники APK v1.0 (важно для сохранения ранее сделанных GPS, истории и экранов). Не пытаться продолжать редактировать только dex внутри APK.
2. Проверить сборку отдельного preview, интерфейс на обычном Android, GPS, OSM, lifecycle карты, scroll-производительность и удобство форм.
3. Интегрировать премиальный экран и контракт координат в реально актуальную кодовую базу.
4. Запустить ограниченный пилот с сотрудником-оператором до установки автоматики.
5. Только после юридической, платёжной и страховой готовности переходить к бесконтактной аренде с телематикой.
