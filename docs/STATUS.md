# Статус проверки — 17 октября 2026 · DEMO 0.2

Реализовано:
- Нативный Android (Kotlin + Compose), нативный iOS (SwiftUI), единый FastAPI backend с SQLite для локального демо.
- Локальная адаптивная веб-панель `/admin` для редактирования тестового автопарка, защищённая демонстрационным ключом `X-Admin-Key`.
- Администратор может добавлять автомобили, редактировать название, тип, грузоподъёмность, объём, КПП, цены, место выдачи, описание и HTTPS-ссылку на фото; публиковать/скрывать карточки.
- Поля редактируются в БД сервера, обновляются на Android кнопкой «Обновить» и на iOS обновлением списка; не требуется пересборка приложений.
- Заполненные данные сохраняются при рестарте и повторном вызове seed; цена уже созданной брони не меняется; скрытый автомобиль не доступен для новых заявок.
- Тесты backend, включающие контроль доступа, валидацию, сохранность бронирований и изменение каталога.

НЕ реализовано / нельзя использовать для настоящей аренды:
- Реальная SMS-регистрация, документы, проверка прав, электронное подписание, страховка, платежи, настоящие клиентские данные.
- Поддержка банковской оплаты, залогов, фотоактов, карты, GPS и бесключевого доступа.
- Многопользовательская роль администратора, 2FA, продакшен-хостинг, PostgreSQL, безопасная загрузка изображений и резервное копирование.
- Сборки APK/IPA: Android SDK / Gradle / macOS Xcode не доступны в этом окружении.

Демо API и админку не публиковать в открытый Интернет: ключ доступа рассчитан только на тестовый локальный запуск.
